# Milestone 0 — Setup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the old codebase with a clean React 19 + TanStack Router + Vite 8 + TypeScript 7 app shell that has placeholder pages for every route. It is linted by Biome, smoke-tested by Playwright with axe, checked in GitHub Actions, and deployed to `fold.ppconde.com` on Cloudflare.

**Architecture:**
- A single-page app. TanStack Router generates file-based routes under `src/routes/`.
- An `AppShell` root layout owns the ☰ menu (a native `<dialog>`) and the text-size setting (a CSS variable persisted in localStorage).
- Static assets are served by Cloudflare Workers with an SPA fallback.

**Tech Stack:** pnpm, React 19, @tanstack/react-router + @tanstack/router-plugin, Vite 8, @vitejs/plugin-react, TypeScript 7, Vitest, Playwright + @axe-core/playwright, Biome 2, Wrangler.

**Spec:** `docs/superpowers/specs/2026-10-04-fold-restart-design.md`, sections 3, 4 and 13. Milestone 0 in section 14.

## Global Constraints

- Package manager: pnpm only. No `package-lock.json`. `packageManager` is pinned in `package.json`.
- All dependencies are installed at their latest version at setup time. No version ranges are hand-written.
- Linting and formatting: Biome only. Use 2-space indent, 120 columns, single quotes, no trailing commas, semicolons, LF.
- The license is GPLv3: a `LICENSE` file with the full text, and `"license": "GPL-3.0-or-later"`.
- English UI copy.
- Tap targets ≥ 44px. Visible focus. Every text pair passes WCAG AA.
- Palette tokens:
  - ivory `#F7F3EA`
  - off-white `#FBF9F4`
  - beige `#E9E1D1`
  - charcoal `#2B2A28`
  - terracotta `#B8613F`
  - indigo `#2E3A59`
- Breakpoint for desktop layouts: 900px.
- Deploy only through Cloudflare's Git integration. The build command is `pnpm biome ci && pnpm vitest run && pnpm build`, where `build` = `vite build && tsc --noEmit`.
- If TypeScript 7 breaks the router plugin or `tsc --noEmit`, install `typescript@5.9` instead and add one line to the README saying why.

## Review Focus

1. **Deep links on the deployed site.** Opening `https://fold.ppconde.com/library` directly, or reloading on it, must serve the app, not a Cloudflare 404. Covered by the manual check in Task 4, Step 5.
2. **Text-size setting when localStorage throws** (Safari private mode, blocked storage). The menu must still work and the size applies for the visit. Covered by `text-scale.test.ts` in Task 2.
3. **Unknown URLs** like `/fold` (no id) or `/nope` show "Page not found" with a way back, never a blank page. Covered by an e2e test in Task 2.
4. **Keyboard-only use of the menu.** It opens with Enter, Esc closes it, and focus is trapped while it's open (native `<dialog>`). Covered by an e2e test in Task 2.
5. **Phone-width layout.** The ☰ button never overlaps the page heading at 375px wide. Covered by the e2e bounding-box check in Task 2.

- [ ] **Step 6: Implement `src/shell/text-scale.ts`**

```ts
export const TEXT_SCALES = [1, 1.15, 1.3] as const;
export type TextScale = (typeof TEXT_SCALES)[number];

const KEY = 'fold:textScale';

export function readTextScale(): TextScale {
  try {
    const stored = Number(localStorage.getItem(KEY));
    return TEXT_SCALES.find((s) => s === stored) ?? 1;
  } catch {
    return 1;
  }
}

export function setTextScale(scale: TextScale): void {
  document.documentElement.style.setProperty('--text-scale', String(scale));
  try {
    localStorage.setItem(KEY, String(scale));
  } catch {
    // Storage blocked (e.g. private mode): the size still applies for this visit.
  }
}

export function applyStoredTextScale(): void {
  setTextScale(readTextScale());
}
```

`src/shell/AppShell.tsx`:

```tsx
import { Link, Outlet } from '@tanstack/react-router';
import { useRef, useState } from 'react';
import styles from './AppShell.module.css';
import { readTextScale, setTextScale, TEXT_SCALES, type TextScale } from './text-scale';

const LINKS = [
  { to: '/', label: 'Home' },
  { to: '/library', label: 'Library' },
  { to: '/editor', label: 'Editor' },
  { to: '/about', label: 'About' }
] as const;

const SCALE_BUTTONS = [
  { glyph: 'A', label: 'Normal text' },
  { glyph: 'A+', label: 'Large text' },
  { glyph: 'A++', label: 'Larger text' }
];

export function AppShell() {
  const menu = useRef<HTMLDialogElement>(null);
  const [scale, setScale] = useState<TextScale>(readTextScale);
  const close = () => menu.current?.close();

  return (
    <>
      <header>
        <button
          type="button"
          className={styles.menuButton}
          aria-label="Menu"
          onClick={() => menu.current?.showModal()}
        >
          ☰
        </button>
      </header>
      <dialog ref={menu} className={styles.menu} aria-label="Menu">
        <nav>
          <ul>
            {LINKS.map((link) => (
              <li key={link.to}>
                <Link to={link.to} onClick={close}>
                  {link.label}
                </Link>
              </li>
            ))}
          </ul>
        </nav>
        <fieldset className={styles.textSize}>
          <legend>Text size</legend>
          {TEXT_SCALES.map((s, i) => (
            <button
              key={s}
              type="button"
              aria-label={SCALE_BUTTONS[i].label}
              aria-pressed={scale === s}
              onClick={() => {
                setTextScale(s);
                setScale(s);
              }}
            >
              {SCALE_BUTTONS[i].glyph}
            </button>
          ))}
        </fieldset>
        <button type="button" className={styles.close} onClick={close}>
          Close
        </button>
      </dialog>
      <Outlet />
    </>
  );
}
```

### Task 3: GitHub Actions CI

**Files:**
- Create: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: the scripts from Task 1 and the Playwright config from Task 2.
- Produces: a `CI` workflow with a `check` job, used as the required status check for PRs to `main`.

- [ ] **Step 1: Write `.github/workflows/ci.yml`**

```yaml
name: CI

on:
  pull_request:
  push:
    branches: [main]

jobs:
  check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v5
      - uses: pnpm/action-setup@v4
      - uses: actions/setup-node@v5
        with:
          node-version-file: .node-version
          cache: pnpm
      - run: pnpm install --frozen-lockfile
      - run: pnpm biome ci
      - run: pnpm vitest run
      - run: pnpm exec playwright install --with-deps chromium
      - run: pnpm test:e2e
      - uses: actions/upload-artifact@v4
        if: failure()
        with:
          name: playwright-report
          path: playwright-report/
```

`pnpm test:e2e` runs `pnpm build` through Playwright's `webServer`, so the type check runs here too. Browsers are reinstalled each run (about a minute).
`# ponytail: cache ~/.cache/ms-playwright keyed on the Playwright version if CI time starts to hurt.` Put this as a YAML comment above the install step.
